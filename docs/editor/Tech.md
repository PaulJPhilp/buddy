# Tech Stack Document

## Title: Effect Schema to React Form Editor - Tech Stack

### 1. Core Languages:
*   **TypeScript:** This is the foundational language for the entire project, ensuring strong type safety across schema definitions, the form description layer, and all React components. It provides a robust development experience and helps catch errors early.

### 2. Frontend Frameworks & Libraries:
*   **React:** Chosen as the primary UI library for building the web application's user interface. Its component-based architecture is well-suited for a modular and dynamic form generation system.
*   **Effect (`@effect/schema`):** This library is central to the project, providing the powerful and extensible schema definition capabilities from which our forms will be generated.
*   **Tailwind CSS:** A utility-first CSS framework will be used for rapid and consistent styling of all form components, allowing for highly customizable designs directly in the markup.
